##### 项目一：餐小美｜团餐 AI Agent 产品矩阵

**【项目背景】**

依托美餐企业团餐平台服务 4,000+ 家客户、承接日均 190 万点餐人次的业务背景，调研梳理传统点餐流程中的三类核心用户痛点：
1. 企业用餐人员｜漏点餐、餐补浪费造成 GMV 流失：有效问卷样本中，68% 的用户每月至少 2 次因错过截单时间无法点餐，83% 的用户每月至少一次存在餐补余额到期清零；同时，选餐决策耗时长，个性化健康饮食需求无法满足；
2. 企业管理员｜管理操作与消费查询低效：人员、餐补及用餐计划等任务分散在多个模块，需跨页面逐项操作；花费查询依赖人工摘数、核对和多维下钻，操作成本高；
3. 美餐内部客服坐席｜重复应答与人力成本高：订单售后、餐补规则等高频重复问题占人工客服会话的 57%，转人工率高达 88%；

作为项目负责人，0-1-N 规划并推动餐小美由 FAQ 问答机器人升级为基于 LLM + Agent + MCP + Skills 的团餐 AI 助手，以统一自然语言入口连接知识与业务系统，形成"能答、能查、能办、能辅助决策"四类能力；基于"一套后端、多端复用、多租户隔离"构建三类角色 Agent 矩阵：
- 用餐人员 Agent：承接选餐规划、餐补消费配置、订单售后、规则查询及健康饮食需求；
- 客户管理员 Agent：承接花费查询、多维下钻、异常监控，以及人员、餐补和用餐计划等高频管理操作；
- 美餐内部 · 客服坐席 Agent：承接 AI 会话提炼、跨模块核查、辅助坐席回复及工单辅助

**【项目目标】**

以任务完成率达到 85% 以上为核心目标，结合转人工率降至 20% 以下、用户满意度达到 4.5 分以上，减少人工介入并优化用户体验。

**【核心工作】**

1. 多角色需求调研与 AI 产品规划：作为项目负责人，联合运营与客服团队，主导面向多角色的需求调研，综合 4,000 份用餐人员问卷、客户管理员与客服坐席访谈、客服会话及工单、点餐行为数据，还原核心业务链路，识别高频问题，确定三类 Agent 的优先落地场景。
2. 产品架构规划与能力体系升级：主导餐小美由 FAQ 客服机器人向多角色 Agent 矩阵升级，规划"知识问答→效果增强→业务执行→复杂编排→能力复用"的演进路径（V1.0 RAG → V2.0 Advanced RAG → V3.0 Agent 转型 → V4.0 ReAct 编排 → V5.0 Skills 沉淀）。
3. 平台级数据底座建设：梳理 2,000+ 份多源异构资料，建设 4 个企业问答知识库和 2 个 ChatBI 知识库，沉淀 36 项指标、18 个维度、150+ 条别名映射与 300+ 组典型样例。
4. Agent 核心链路设计与复杂任务编排：搭建完整意图识别→路由分发→RAG／MCP／Skill／ReAct 分层执行链路，将意图识别准确率由 83% 提升至 95%，检索准确率由 75% 提升至 94%，平均响应时延压缩至 2.5 秒以内。
5. 评测驱动的模型选型与迭代优化：构建 2,000+ 条离线评测集，建立"评测→统计→归因→优化→回归"闭环，推动 5 轮版本迭代。

**【项目成果】**
1. 核心产品指标：任务完成率达到 87%，转人工率降至 17%，用户满意度评分 4.6 分；
2. 业务价值验证：
   - to 用餐企业：点餐决策时长由 4.2 分钟缩短至 2 分钟以内，餐补金额使用率由 72% 提升至 93%；月度 GMV 增量约 800 万元；管理员花费查询耗时由 20-40 分钟缩短至 1 分钟以内。
   - to 美餐内部：单个客服事件处理时长由约 5 分钟缩短至 2 分钟以内；沉淀 9 个 Skills 能力包、17 套标准 Workflow 及 16 个 MCP 工具。

##### 项目二：Paperwork｜美餐客户管理平台

**【项目背景】**

Paperwork 是美餐面向企业及机构客户管理员的团餐管理后台。企业管理员通过平台管理组织与用餐人员，完成用餐配置、订单查询与账单分析等。接手时产品仅支持基础人员管理，多项高频配置依赖美餐运营协作，自助化程度低。

**【核心工作】**

1. 产品规划与架构重构：作为项目负责人，主导 0-1-N 平台建设，负责产品规划、版本拆解，围绕企业管理员核心任务重构业务域及信息架构；将单一人员管理工具升级为覆盖人员、用餐配置、订单、账单、数据分析及权限的一体化管理平台，并完成英文区及 PC、移动 Web 适配。
2. 人员与用餐管理自助化：建设组织架构、人员管理、批量处理及邀请入企能力，打通第三方平台与 Paperwork 的人员数据同步；将餐标、餐补及用餐计划等配置由美餐运营侧迁移至客户侧，实现高频管理任务自助闭环。
3. 订单与业财结算闭环：梳理订单、消费、账单与结算关系，建设订单及消费明细查询、多维筛选与汇总、财务账单及结算等能力，形成从订单查询、消费分析到财务结算的业务闭环。
4. 数据可视化与安全审计升级：整合人员、消费、餐补及订单数据，建设面向行政、HR、财务和管理层的数据看板；完善多维权限、登录安全及管理员日志，实现关键操作与敏感信息访问全量留痕。

**【业绩成果】**

升级后的平台服务中国及欧洲市场 4,000+ 家客户，关键管理任务自助完成率约 90%，高频任务处理时长降低约 80%，月度经营汇报准备时间由约半个工作日缩短至 30 分钟。
